Interactive Sankey Diagrams

This page provides interactive Sankey diagrams of laying-hen movement transitions. Diagrams are provided for pooled data and for each pen separately, across four production stages. Both looping transitions and non-looping transitions versions are included.

In each diagram, links represent transition pathways between functional areas. Hover over links to inspect transition rates and raw counts.

Diagrams display the top 20% of transitions by raw count for clarity.

Node colours follow the coding shown in Figure 1 of the manuscript (aviary layout and functional areas).
